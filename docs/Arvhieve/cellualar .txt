
### 3. Extracting and Patching the Modem Firmware (Modem Firmware Patching)

This is the most critical step. We must eliminate the network authentication requirement.

**Step 1: Extracting the Firmware:**
On the rooted Phone A, in a terminal app or via ADB shell:
```bash

```
We will transfer the `modem.img` file to the computer.

**Step 2: Patching Using a Hex Editor:**
Open `modem.img` in a Hex editor. Search for byte sequences representing the authentication rejection routine. In GSM networks, the network asks for the IMSI from the SIM. Instead, we will find the routine that checks for the SIM's presence and make it skip the check.

- Search for the text strings `SIM` or `IMSI`.
- Look for conditional branch instructions (Branch if Equal) in ARM machine code. Our goal is to find the code that says: "If no SIM -> reject connection."
- Replace it with a `NOP` (No Operation) instruction or an unconditional branch so that the program continues as if the SIM were present.
- More advanced: search for the `mm_rr_authenticate_req` function in the Mobility Management layer code. Make it always return "1" (success).

**Step 3: Bypassing the Digital Signature (Secure Boot):**
This is the biggest obstacle. You cannot simply flash the modified `modem.img` because the bootloader will reject it if signature verification is enforced.
- **For Qualcomm:** If the bootloader is unlocked, you can flash it. If locked, you must find an exploit. Some versions of the QFIL tool allow flashing in "Emergency Download Mode" (EDL) with force. Boot the phone into EDL mode (by shorting test points on the motherboard or using `adb reboot edl`). Use a QFIL command to bypass signature checks:
  ```bash
  qfil -f prog_emmc_firehose.mbn -r modem.img -t /dev/ttyUSB0
  ```
- **For MediaTek:** Use SP Flash Tool with a Scatter file. Load the modified `modem.img`. In some versions, you can bypass the signature check by enabling the "Force Write" option or using a special build of the download tool.

**The Safer Method (Live Memory Patching):**
Instead of permanent flashing, we can copy the modified code into the modem's RAM via the DIAG port after each boot. This requires knowing the memory address of the target function. Using a DIAG (or QMI) memory-write command, we can inject directly. This is what our APK will do. We will write C code in the app that sends a QMI packet to write memory.
